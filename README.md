# Cyber Campaign

A cyber security learning hub: domains, threats, best practices, emerging technologies, training resources, and a quiz.

## About

Cyber Campaign brings together information on the main domains of cyber security, common threats, recommended practices, and emerging technologies. It’s aimed at students and anyone building a foundation in cyber security.

**What’s included:**

- **Domains** — Network, application, cloud, endpoint, IoT, data, and IAM
- **Threats** — Malware, phishing, ransomware, social engineering, DDoS, data breaches, insider threats, APTs
- **Practices** — Passwords, 2FA, updates, backups, least privilege, encryption, awareness
- **Emerging** — AI in security, zero trust, supply chain security, privacy-enhancing technologies
- **Training** — Links to TryHackMe, HackTheBox, OverTheWire, PortSwigger, and YouTube channels
- **Quiz** — Multiple-choice questions with feedback and short explanations

## Tech stack

- [Next.js](https://nextjs.org) (App Router)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- TypeScript

## Getting started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Build for production:

```bash
npm run build
npm start
```
